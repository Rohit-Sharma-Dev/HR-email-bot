# Resumes Folder 📄

Place your actual resume PDF files here with these exact names:

1. `frontend-resume.pdf`  (Attached when Role Category contains "Frontend")
2. `backend-resume.pdf`   (Attached when Role Category contains "Backend")
3. `fullstack-resume.pdf` (Attached when Role Category contains "Fullstack")

*Note: The bot will automatically check for `.pdf`, `.docx`, or `.doc` extensions for each role category.*
